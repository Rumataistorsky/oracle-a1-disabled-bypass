# 09 — Телефон-міст і Telegram

## Телефон як тимчасовий трекер — РОЗГОРНУТО

Base year тікає з дня набуття авто, а FMM003 ще не замовлений. Виділений
телефон закриває цей розрив справжніми GPS-поїздками замість рукописного CSV.

### Що піднято

| | |
|---|---|
| Ендпойнт | **`https://gps.rotes.ca`** |
| Протокол | `osmand` (HTTP), Traccar порт **5055** |
| Маршрут | Cloudflare Tunnel (LXC 405) → `192.168.2.66:5055`, **повз Caddy** |
| DNS | CNAME у Cloudflare + запис у Pi-hole (`192.168.2.14`) |
| Пристрій | `Phone bridge (Roman)`, прив'язаний до Pacifica у `fleet.vehicles` |

Перевірено наскрізно: правильний ідентифікатор → `HTTP 200`, чужий → `HTTP 400`.
Тестова позиція після перевірки видалена.

### Безпека

Ендпойнт публічний, тож **ідентифікатор пристрою і є єдиний секрет**. Тому це
32 hex-символи, а не `phone-roman`: інакше будь-хто, хто вгадає ім'я, зможе
підсовувати позиції в податковий документ. Traccar відхиляє невідомі
ідентифікатори, тож засмітити базу чужими даними не вийде.

Ідентифікатор — у `/root/fleet-credentials.txt` на pve, розділ
`Traccar Client (телефон-міст)`.

### Налаштування застосунку

**Traccar Client** (Android або iOS):

```
Server URL:        https://gps.rotes.ca
Device identifier: <з fleet-credentials.txt>
Location accuracy: High
Frequency:         30 s
Distance / Angle:  0
Service status:    ON
```

Обов'язково зняти обмеження енергозбереження для застосунку, інакше система
приспить його і дані тихо припиняться. Це головна слабкість схеми з телефоном.

### Обмеження, які лишаються

* **Немає сигналу запалювання.** Поїздки визначаються по руху, тож прогулянка
  пішки чи поїздка пасажиром у чужому авто попадуть у логбук. Телефон має
  лишатися в машині, а не ходити з людиною.
* **Тихе засинання.** Саме тому алерт watchdog «пристрій мовчить понад 36 год»
  критичний — він перетворює тиху втрату даних на помітну.
* **Точність.** GPS-пробіг відхиляється від одометра. Раз на місяць звіряти,
  допуск 3%.

### Перехід на FMM003

Коли приїде трекер — **спершу вимкнути застосунок на телефоні**, і лише потім
підключати FMM003. Якщо обидва звітуватимуть одночасно, кілометри задвояться.

```sql
UPDATE fleet.vehicles
   SET traccar_device_id = <id нового пристрою>
 WHERE vin = '2C4RC1GGXSR535286';
```

Старий пристрій у Traccar не видаляти — на ньому висить історія base year.

## Telegram: потрібна група, а не канал

**Канал односторонній** — пишуть лише адміни, і Алекс там відповідати не зможе.
Для сценарію «обидва пишуть і обидва отримують питання» правильний примітив —
**супергрупа**.

Додатковий виграш: у групі `callback_query` повідомляє **хто саме** натиснув
кнопку (`from.id`). Класифікація автоматично приписується правильному водію,
і особисті км Романа й Алекса рахуються окремо — рівно те, що потрібно для
розрахунку benefit по кожному з них.

### Налаштування

1. **Окремий бот** через `@BotFather` — наприклад `ROTES Logbook`.
   Не перевикористовувати наявний `TELEGRAM_BOT_TOKEN`: інакше Алекс отримає
   доступ до решти автоматизацій.
2. **Група** `ROTES Logbook`, додати бота адміністратором.
3. **Вимкнути privacy mode**: `@BotFather → /setprivacy → Disable`.
   Інакше бот не побачить фото чеків — лише команди.
4. **Дізнатись chat_id** групи (він від'ємний, формату `-100…`):

```bash
curl -s "https://api.telegram.org/bot<TOKEN>/getUpdates" | jq '.result[].message.chat.id'
```

5. Вписати в базу:

```sql
UPDATE fleet.drivers SET chat_id = '<-100…>' WHERE label = 'Roman';
INSERT INTO fleet.drivers (label, role, home_is_office, chat_id)
VALUES ('Alex', 'employee', false, '<-100…>');
```

> `home_is_office = false` для Алекса принципово: його дім не є офісом компанії,
> тож його поїздки дім ↔ база — це commuting, тобто особисті км.
> Найчистіше — авто ночує на базі, тоді в нього особистих км немає взагалі.

### Що бот робитиме в групі

* ввечері викладає картки поїздок із кнопками `Оцінка` / `Обʼєкт` / `Постачальник` / `Особисте`;
* приймає фото чеків і одометра;
* шле алерти watchdog;
* раз на місяць — зведення: бізнес-%, некласифіковані, черга відшкодувань.

Обидва бачать одну стрічку — ніхто не дублює роботу і видно, хто що закрив.
