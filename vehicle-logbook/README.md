# Corporate Vehicle Logbook — ROTES SMART Construction Inc.

Self-hosted логбук корпоративного авто під вимоги CRA, побудований на наявній
homelab-інфраструктурі (Proxmox `pve` 192.168.2.230).

## Навіщо

Авто оформлене на компанію. Без логбука CRA нараховує повний standby charge
(~$11 300/рік) плюс operating benefit на весь пробіг. З коректним логбуком
і низьким особистим пробігом сумарний taxable benefit падає до ~$900–2 700.

**Різниця ≈ $10 000 оподатковуваного доходу на рік.** Це і є бюджет проєкту.

Деталі розрахунку — [`01-compliance-cra.md`](./01-compliance-cra.md).

## Порядок впровадження

1. **День 0 (негайно, не чекаючи заліза).** Фото одометра. Ручний облік у
   Nextcloud Tables за формою з `01`. Base year стартує з дня набуття — його
   не можна відтворити заднім числом.
2. **Тиждень 1.** Замовити Teltonika FMM003 + LTE-M SIM (`02`).
3. **Тиждень 2.** LXC 426 Traccar (`03`), схема БД (`04`), geofences.
4. **Тиждень 3.** n8n-воркфлоу (`05`), бот класифікації.
5. **Тиждень 4.** Metabase-дашборд і експорт (`06`). Памʼятка водію (`07`),
   підписана політика (`08`).
